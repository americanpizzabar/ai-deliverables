# 有機EL照明機器 制御・管理システム (Leo-OLED Control System) 要件定義書

## 1. 概要

本要件定義書は、ECUANEST合同会社が新規開発を検討している有機EL照明機器に対し、その先進的な特性（薄型・軽量・フレキシブル性、面発光、高演色性、調光調色機能など）を最大限に引き出し、ユーザーが直感的に制御・管理できるWebベースのシステム「Leo-OLED Control System」の企画および初期要件を定めるものです。

マーケティング調査書で示された「スマート化との連携」のトレンドと、ターゲットペルソナ「革新的な空間デザイナー 佐藤 健太」のニーズに応えるため、IoT技術を基盤とした照明制御・監視機能を提供し、デザイン性と機能性を両立する空間演出を支援します。

## 2. 背景

有機EL照明は、そのユニークな特性から高付加価値市場での成長が期待されています。特に、デザイン性の追求、高演色性、調光調色機能、低発熱、省エネルギーといった点が評価され、自動車照明、建築・インテリア照明、医療・美容分野での用途多様化が進んでいます。

調査書では、これらの特性を活かしつつ、「IoT技術との連携により、スマートホーム/ビルディングシステムの一部として、光の制御やデータ収集が可能になる動き」がトレンドとして挙げられています。このトレンドに対応し、物理的な有機EL照明機器のポテンシャルを最大限に引き出すためには、柔軟かつ高度な制御・管理を可能にするデジタルプラットフォームが不可欠です。

本システムは、有機EL照明機器の導入を検討する建築設計事務所や空間デザイナー、施設管理者といったB2B顧客が、照明の設置から運用、保守までを効率的かつ効果的に行えるよう支援することを目的とします。

## 3. 目的

本システムの主な目的は以下の通りです。

*   **有機EL照明の高度な制御:** 個別またはグループ単位での調光調色、シーン設定、スケジュール管理を可能にし、多様な空間演出ニーズに応える。
*   **複数照明の一元管理:** 設置された多数の有機EL照明デバイスをWebインターフェースから容易に登録、監視、制御できるようにする。
*   **デザインと機能性の両立支援:** デザイナーが意図する光環境を直感的に設定・再現できるUI/UXを提供し、デザインの自由度と実現性を高める。
*   **省エネ運用支援:** 照明の稼働状況や消費電力を可視化し、効率的な運用をサポートすることで、環境負荷の低減に貢献する。
*   **将来的な拡張性確保:** IoTデバイスとの連携を前提としたアーキテクチャを採用し、将来的な機能拡張（センサー連携、AIによる自動最適化など）に備える。

## 4. ターゲットユーザー

主要ターゲットペルソナは、マーケティング調査書で定義された「革新的な空間デザイナー 佐藤 健太」です。

*   **ペルソナ名:** 革新的な空間デザイナー「佐藤 健太」
*   **ニーズ:**
    *   従来の照明では実現できない、ユニークで洗練された空間演出。
    *   照明の存在感を消しつつ、空間全体を均一に明るく、目に優しい光。
    *   薄型・軽量・フレキシブルな照明によるデザインの制約解消。
    *   高演色性で、素材や展示物の色を忠実に再現できる照明。
    *   省エネ性も考慮しつつ、他社との差別化を図れる先進的なソリューション。
*   **本システムが提供する価値:**
    *   直感的なUIで、デザイン意図通りの光環境を容易に設定・調整できる。
    *   複数の有機EL照明を効率的に管理し、複雑なシーンも一括で制御可能。
    *   リアルタイムなフィードバックにより、試行錯誤しながら最適な空間を創造できる。

その他、施設管理者、保守担当者もサブターゲットとして想定します。

## 5. 機能要件

### 5.1. 認証・ユーザー管理機能

*   ユーザー登録、ログイン、パスワードリセット機能。
*   ロールベースアクセス制御（管理者、デザイナー、閲覧者など）。
*   プロジェクト単位でのアクセス権限管理。

### 5.2. 照明デバイス登録・管理機能

*   有機EL照明デバイスの新規登録、編集、削除。
*   デバイスの物理的な設置場所、名称などのメタデータ管理。
*   複数のデバイスをグループ化し、一括制御を可能にする機能。
*   デバイスの状態（オンライン/オフライン、稼働状況）の表示。

### 5.3. 調光調色制御機能

*   個別デバイスおよびグループ単位での明るさ（調光）調整。
*   色温度（暖色〜寒色）調整。
*   RGBまたはHSLモデルによる色（調色）調整（対応デバイスの場合）。
*   リアルタイムでの照明設定変更反映。

### 5.4. シーン・スケジュール設定機能

*   現在の照明設定を「シーン」として保存し、ワンクリックで呼び出せる機能。
    *   例: 「昼間オフィスモード」「夜間リラックスモード」「展示品強調モード」
*   複数のシーンを組み合わせた「シーケンス」作成機能。
*   特定の日時、曜日、期間に基づいてシーンを自動適用するスケジュール機能。

### 5.5. モニタリング・レポート機能

*   各デバイスおよびグループの稼働状況（点灯時間、エラー履歴など）のリアルタイム表示。
*   消費電力の可視化（リアルタイム、日次、月次レポート）。
*   異常発生時のアラート通知機能（メール、システム内通知）。

### 5.6. プロジェクト・フロア管理機能

*   複数のプロジェクト（例: ホテルA、オフィスB）を管理できる機能。
*   各プロジェクト内で、フロアやエリアごとに照明を分類・表示できる機能。
*   平面図上に照明デバイスの配置を表示し、直感的に選択・制御できるUI（将来的な拡張）。

## 6. 非機能要件

*   **パフォーマンス:**
    *   照明制御コマンドの応答時間は1秒以内。
    *   UIの操作は滑らかで、遅延を感じさせないこと。
*   **セキュリティ:**
    *   ユーザー認証は業界標準の安全なプロトコル（OAuth2, JWTなど）を使用。
    *   通信はHTTPS/WSSで暗号化。
    *   データは暗号化して保存し、不正アクセスから保護。
*   **スケーラビリティ:**
    *   数百台規模のデバイスと数十ユーザーの同時利用に耐えうる設計。
    *   将来的なデバイス数、ユーザー数の増加に対応可能なアーキテクチャ。
*   **ユーザビリティ:**
    *   直感的で分かりやすいUI/UXデザイン。
    *   レスポンシブデザインにより、PC、タブレットからのアクセスに対応。
    *   多言語対応（将来的な拡張）。
*   **信頼性:**
    *   システム稼働率99.9%以上を目指す。
    *   デバイスとの通信断絶時も、システムは安定稼働し、復旧時に自動再接続を試行。
*   **保守性:**
    *   モジュール化されたコードベースで、機能追加や改修が容易なこと。
    *   適切なロギングとモニタリングにより、問題発生時の原因特定が容易なこと。
*   **互換性:**
    *   主要なWebブラウザ（Chrome, Firefox, Safari, Edgeの最新版）に対応。

## 7. 技術スタック (案)

*   **フロントエンド:** Next.js (React), TypeScript, Tailwind CSS
*   **バックエンド:** Node.js (Express.js または NestJS), TypeScript

*   **認証:** NextAuth.js / Auth0 など

## (2) 実装方針および主要なソースコード断片

### 1. 実装方針

本システムは、有機EL照明機器の制御・管理を目的としたWebアプリケーションとして開発します。MVP (Minimum Viable Product) として、基本的なデバイス登録、グループ化、調光調色制御、およびシーン設定機能に焦点を当てます。

*   **アーキテクチャ:**
    *   **フロントエンド:** Next.js (Reactベースのフレームワーク) を採用し、高速な開発と優れたユーザー体験を提供します。TypeScriptを使用し、型安全な開発を推進します。UIフレームワークとしてTailwind CSSを検討し、柔軟なデザインを実現します。
    *   **バックエンド:** Node.js (Express.js) を採用し、RESTful APIとWebSocketによるリアルタイム通信を提供します。これもTypeScriptで記述します。
    *   **データベース:** PostgreSQLを使用し、デバイス情報、ユーザー情報、シーン設定などを永続化します。
    *   **リアルタイム通信:** 照明デバイスへのコマンド送信と状態更新のためにWebSocketプロトコルを採用します。これにより、ユーザーインターフェースがリアルタイムでデバイスの状態を反映し、制御コマンドが即座にデバイスに伝達されます。
*   **UI/UXの考慮:** 有機EL照明の「薄型・軽量・フレキシブル性」「面発光」「均一な光」といった特性を視覚的に表現できるような、クリーンで直感的なデザインを心がけます。特に調光調色インターフェースは、デザイナーが感覚的に操作できるようなUXを重視します。
*   **MVPの範囲:**
    *   ユーザー認証（ログイン/ログアウト）
    *   照明デバイスの
